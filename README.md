# PlayLandGames_Test

## Collectable Items System

### Що було реалізовано

Система підбираємих предметів з анімованими об'єктами та спавнером. Основна ідея побудована навколо абстрактного базового класу `BaseCollactableItem`, який задає єдиний інтерфейс для всіх предметів, дозволяючи кожному типу визначати власну логіку анімації.

---

### Унікальна особливість — Анімація через наслідування

Замість того щоб розміщувати всю логіку анімації в одному класі, я використав **абстрактне наслідування** для розділення поведінок:

- `RotateItem` — безперервно обертає об'єкт навколо осі Y щокадру
- `SinusoidalItem` — рухає об'єкт вгору-вниз за допомогою синусоїди на основі `Time.time`, створюючи плавний ефект ширяння

Кожен підклас просто перевизначає метод `Animation()`, який викликається щокадру з `Update()` базового класу. Це дозволяє легко додавати нові типи анімацій без змін у вже існуючому коді.

---

### Використані компоненти Unity

- **MonoBehaviour** — базовий клас для всіх скриптів
- **Transform** — використовується для обертання (`Transform.Rotate`) та маніпуляцій з позицією в обох типах анімації
- **Time.deltaTime / Time.time** — для незалежного від частоти кадрів обертання та обчислення синусоїди
- **Mathf.Sin** — для синусоїдального руху ширяння
- **GameObject.SetActive(false)** — для деактивації зібраних предметів
- **Object.Instantiate** — використовується в `CollactableItemSpawner` для спавну префабів у випадкових позиціях
- **SerializeField** — для відображення параметрів в інспекторі Unity без оголошення їх публічними

---

### Як працює спавнер

`CollactableItemSpawner` отримує список префабів предметів і спавнить задану кількість (`_spawnSize`) у випадкових позиціях в межах налаштовуваного 2D діапазону (`_spawnRange`) під час старту сцени.
